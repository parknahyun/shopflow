# 샵플로우(ShopFlow)

여러 판매자가 입점하는 이커머스 쇼핑몰입니다. 고객은 상품을 담아 안전하게 결제하고, 판매자는 자기 주문의 배송, 정산, 환불을 따로 관리합니다.

> 현재 상태: 기획 초기 단계입니다. 개발 원칙(헌법)만 정해져 있고, 기능 명세와 코드는 아직 없습니다.

## 만들려는 것

- 상품을 보고 장바구니에 담아 주문하고 결제하는 쇼핑몰
- 판매자별로 나뉘는 배송, 정산, 환불
- 결제 전에 재고를 선점하고, 재시도가 겹쳐도 결제가 한 번만 일어나는 안전한 결제
- 배송 완료 후 수수료를 공제하는 정산과, 부분 환불까지 다루는 환불

## 기술 스택

- 스프링 부트(자바)
- 타임리프(서버 사이드 템플릿 엔진)
- 스프링 시큐리티, 스프링 데이터

빌드 도구, 데이터베이스, 결제 대행사는 아직 정하지 않았고 계획 단계에서 결정합니다.

## 개발 원칙

모든 원칙은 [헌법](.specify/memory/constitution.md)에 있습니다. 핵심만 요약하면 다음과 같습니다.

1. 테스트를 먼저 작성합니다(테스트 주도 개발).
2. 결제와 보안의 신뢰성을 지킵니다.
3. 주문과 재고의 정합성을 지킵니다.
4. 가장 단순한 설계로 시작합니다.
5. 모든 산출물은 한글로, 쉽고 직관적으로 씁니다.
6. 판매자별로 배송, 정산, 환불을 분리해 관리합니다.
7. 재고 선점과 멱등키로 결제를 한 번만 처리합니다.
8. 정산과 환불 규칙은 바꾸기 쉽고 추적할 수 있게 만듭니다.

## 개발 방식

[스펙 킷](https://github.com/github/spec-kit) 순서를 따릅니다.

1. `/speckit-specify`: 기능 명세 작성
2. `/speckit-plan`: 구현 계획 작성
3. `/speckit-tasks`: 작업 목록 작성
4. `/speckit-implement`: 구현

## 폴더 구성

- `.specify/memory/constitution.md`: 프로젝트 헌법
- `.specify/templates`: 명세, 계획, 작업 목록 템플릿
- `.claude/skills`: 스펙 킷 명령
