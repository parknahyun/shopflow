# 계약: 화면 경로 (프론트엔드 참고)

이 문서는 9단계의 **별도 프론트엔드 인스턴스**가 가질 화면 경로의 참고 문서다. 백엔드는 REST API만 내고 화면을 렌더링하지 않는다([ADR-0008](../../../docs/adr/0008-layered-rest-repository.md) 수정, [ADR-0009](../../../docs/adr/0009-review-decisions-payment-refund-scope.md) 결정 C). 프론트엔드는 아래 화면을 보여 주고 백엔드를 HTTP로 호출한다. 백엔드의 REST 경로 계약은 `contracts/rest-api.md`(작업 T030)에 따로 정의하며, 이 문서에는 REST 경로를 적지 않는다.

모든 상태 변경 요청(`POST`)은 사이트 간 요청 위조 방어 토큰과 권한 검사를 거친다. 결제·취소·승인 요청은 멱등키를 담고, 멱등키는 **시도마다 새로 만든다.** **`GET` 경로는 상태를 바꾸지 않는다.** 대행사에서 돌아온 경로(`success`, `fail`)도 읽기 전용이다.

## 공개 (로그인 불필요)

| 메서드 | 경로 | 설명 | 명세 |
|--------|------|------|------|
| GET | `/` , `/products` | 판매 중 상품 목록. 쿼리 `q`(이름 검색), `seller`(판매자별 모아보기), `page` | FR-005 |
| GET | `/products/{공개식별자}` | 상품 상세와 옵션 선택. 품절 조합은 선택 불가로 표시 | FR-005 |
| GET | `/sellers/{공개식별자}` | 판매자별 상품 모아보기 | FR-005 |
| GET, POST | `/signup` | 고객 가입 | FR-001 |
| GET, POST | `/login` | 로그인(고객, 판매자, 운영자 공용) | FR-001 |

| GET | `/cart` | 장바구니 보기 | FR-006 |
| POST | `/cart/items` | 판매 단위와 수량으로 담기 | FR-006 |

| GET | `/orders` , `/orders/{공개식별자}` | 내 주문과 하위 주문별 상태. 확인 필요·환불됨 상태와 환불 진행 상태를 보인다 | FR-014 |

## 판매자 (판매자 계정만)

승인 상태가 아니어도 로그인해서 입점 상태 화면은 볼 수 있다. 상품 등록 등 나머지는 승인된 판매자만 쓴다. 정지된 판매자는 이미 확정된 주문의 발송, 배송 완료, 취소 화면을 계속 쓸 수 있다.

| 메서드 | 경로 | 설명 | 명세 |
|--------|------|------|------|
| GET, POST | `/seller/signup` | 판매자 가입과 입점 신청 | FR-002 |
| GET | `/seller/status` | 내 입점 상태와 거절 사유 확인(승인 전에도 가능) | FR-002, ADR-0009 A3 |
| GET, POST | `/seller/reapply` | 거절된 판매자의 재신청(정보와 서류를 고쳐 다시 제출) | FR-002, ADR-0009 A3 |
| GET | `/seller/products` | 내 상품 목록 | FR-004 |
| GET, POST | `/seller/products/new` | 상품과 옵션 조합 등록(승인 상태만) | FR-003, FR-003a |
| GET, POST | `/seller/products/{상품}/edit` | 상품·옵션 수정, 재고는 **총 보유 수량**으로 입력(동시 수정이면 다시 읽어 확인) | FR-003a, ADR-0009 B4 |
| POST | `/seller/products/{상품}/suspend` | 판매 중지 | FR-003 |
| GET | `/seller/orders` , `/seller/orders/{하위주문}` | 내 하위 주문만 조회(확정된 주문의 것만). 발송 지연 표시 | FR-004, ADR-0009 A2 |
| POST | `/seller/orders/{하위주문}/ship` | 송장 입력, 배송 중으로 변경 | FR-012 |
| POST | `/seller/orders/{하위주문}/deliver` | 배송 완료로 변경 | FR-012 |
| POST | `/seller/orders/{하위주문}/cancel` | 발송 전 판매자 취소(사유 필수). 환불과 재고 가산은 고객 취소와 같은 흐름. 멱등키 필수 | ADR-0009 A2 |

## 오류 응답 규칙

- 권한 없음(다른 사람의 주문, 다른 판매자의 하위 주문): 존재 여부를 알리지 않도록 404로 응답한다.
- 허용되지 않는 상태 변경: 409와 한글 안내 문구.
- 재고 부족, 금액 불일치(고객이 확인한 금액과 서버 계산 총액의 불일치 포함): 사용자에게 보이는 한글 안내와 함께 이전 화면으로 돌려보낸다.
- 같은 멱등키에 다른 내용: 422.
