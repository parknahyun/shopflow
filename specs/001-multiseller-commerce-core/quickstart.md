## 수동 확인 (프론트엔드가 생긴 뒤)

이 백엔드는 REST API만 제공하고 화면은 별도 프론트엔드가 만든다. 아래 절차는 프론트엔드(9단계)가 연결된 개발 환경에서 하며, 그전에는 위의 자동 검증이 기준이다.

1. 포스트그레스큐엘을 실행하고 `./gradlew bootRun`으로 백엔드를 띄운 뒤 프론트엔드를 연결한다.
2. 판매자로 가입하고, 운영자 기능으로 한 번 거절(사유 입력)해 사유가 보이는지 확인한 뒤 재신청하고 승인한다. 옵션이 있는 상품을 등록한다.
3. 고객으로 가입하고, 상품을 검색해 장바구니에 담고 테스트 키로 결제한다. 결제 대기 주문 하나는 결제하지 않고 직접 취소해 본다.
4. 판매자 쪽에서 송장을 입력하고 배송 완료로 바꾼 뒤, 고객 쪽에서 구매 확정을 누른다. 다른 주문에서는 문제 신고를 눌러 자동 확정에서 빠지는지 확인한다.
5. 새 주문으로 발송 전에 고객이 취소하고, 다른 주문은 판매자가 사유를 적어 취소해 재고와 환불이 반영되는지 확인한다.
6. 가상계좌 주문을 만들어 입금 기한 뒤에 입금되게 한 뒤(대행사 테스트 도구), 확인 필요 주문이 자동으로 환불되는지 확인한다.

기대 결과: 각 단계의 결과가 [web-routes.md](contracts/web-routes.md)의 설명과 같고, 하위 주문 상태가 [data-model.md](data-model.md)의 전이 표를 벗어나지 않는다.
