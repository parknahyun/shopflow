# 빠른 시작: 검증 안내

이 문서는 기능이 끝까지 동작하는지 확인하는 방법만 담는다. 구현 코드는 담지 않는다. 설계 내용은 [data-model.md](data-model.md)와 [contracts](contracts/)를 본다.

## 준비물

- 자바 21
- 도커(통합 테스트가 테스트컨테이너스로 포스트그레스큐엘을 띄운다)
- 토스페이먼츠 개발용 테스트 키(수동 확인용, 자동 테스트에는 필요 없다)

## 자동 검증

```text
./gradlew test
```

기대 결과: 모든 테스트가 통과한다. 아래 시나리오는 테스트로 존재해야 한다.

## 수동 확인 (개발 서버)

1. 포스트그레스큐엘을 실행하고 `./gradlew bootRun`으로 서버를 띄운다.
2. 판매자로 가입하고, 운영자 화면에서 승인한 뒤, 옵션이 있는 상품을 등록한다.
3. 고객으로 가입하고, 상품을 검색해 장바구니에 담고 테스트 키로 결제한다.
4. 판매자 화면에서 송장을 입력하고 배송 완료로 바꾼 뒤, 고객 화면에서 구매 확정을 누른다.
5. 새 주문으로 발송 전에 취소해 재고와 환불이 반영되는지 확인한다.

기대 결과: 각 단계의 화면 상태가 [web-routes.md](contracts/web-routes.md)의 설명과 같고, 하위 주문 상태가 [data-model.md](data-model.md)의 전이 표를 벗어나지 않는다.
